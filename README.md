Soy Diego Castellblanco.
Me interesa profundamente el mundo de la programación, los sistemas
y entender cómo funciona la tecnología desde sus cimientos.

Este espacio en GitHub funciona como una bitácora técnica:
aquí encontrarás mis proyectos, pruebas, aprendizajes y errores,
todos parte de mi proceso como estudiante de Ingeniería de Sistemas.

El proyecto más importante en el que trabajo actualmente es
SMED Technology, una iniciativa donde aplico lo que aprendo

Este perfil no representa resultados finales,
representa evolución constante.

experimentar y construir con criterio propio.
